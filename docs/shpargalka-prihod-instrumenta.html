Новый инструмент и приход за 2024 год

Сначала инструмент в справочнике, затем строка в документе «Приход инструмента».

1

Новый инструмент

  1. Меню: Справочники → Товарно-материальные ценности.
  2. Кнопка + Новое наименование (клавиша Insert).
  3. Тип ТМЦ: Инструмент (аренда). Иначе строка не появится в приходе.
  4. Краткое наименование, размер, ед. измерения, папка где храним и артикул.
  5. Галочку Инструмент субаренды не ставить. Приход показывает только свои инструменты.
  6. Сохранить. Открыть карточку снова и через История указать Суточный тариф (аренда). Без тарифа инструмент в приход попадёт, но аренда потом будет без ставки.
2

Добавить в приход

  1. Меню: Инструменты (аренда) → Приход инструмента.
  2. Изменить интервал (строка период: с … по … в шапке журнала): показать документы за 2024 год.
  3. Удалить документ два раза, чтобы он стал непроведённым, и открыть его.
  4. + Добавить инструменты → найти новый инструмент → количество и цена → Жадвалга кушиш.
  5. Нажать кнопку OK.

Печать: Ctrl+P, лист A4, книжная ориентация. В браузере отключите колонтитулы.
